1. Template-Driven Form (FormsModule)

When to use: tiny, low-complexity forms (login, quick admin actions, newsletter signup). Angular builds the form model for you from ngModel; validation rules live directly in the HTML as directives (required, etc.). Least code for simple cases, but harder to scale for dynamic/complex logic.

3. Signal Forms (Experimental)

When to use: new internal/greenfield prototypes where you want forms wired directly into signal-based state, with no RxJS glue — good for a small team building experience with the API. Not recommended yet for customer-facing or business-critical forms, since the API is still experimental and can change without notice.
